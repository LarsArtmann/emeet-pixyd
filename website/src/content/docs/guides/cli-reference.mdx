The `emeet-pixy` binary (symlink to `emeet-pixyd`) sends commands to a running daemon via Unix socket at `/run/emeet-pixyd/socket`.

## Global Flags

```bash
emeet-pixyd --version    # Print version
emeet-pixyd --help       # Show usage
```

## Commands

### Camera Modes

| Command                     | Description                               |
| --------------------------- | ----------------------------------------- |
| `emeet-pixy track`          | Enable AI face tracking                   |
| `emeet-pixy idle`           | Set camera to idle (on but no tracking)   |
| `emeet-pixy privacy`        | Enable privacy mode (hardware lens block) |
| `emeet-pixy toggle-privacy` | Toggle privacy mode                       |

### PTZ Control

| Command                   | Description                             |
| ------------------------- | --------------------------------------- |
| `emeet-pixy center`       | Center camera (pan=0, tilt=0, zoom=100) |
| `emeet-pixy pan <value>`  | Set pan (-150 to 150; or `rel+/-N`)     |
| `emeet-pixy tilt <value>` | Set tilt (-90 to 90; or `rel+/-N`)      |
| `emeet-pixy zoom <value>` | Set zoom (100 to 150; or `rel+/-N`)     |

Bare numbers are treated as **absolute** positions. Use the `rel` prefix for relative moves:

```bash
emeet-pixy pan -90       # Absolute: pan to -90 degrees
emeet-pixy pan rel+10    # Relative: pan 10 degrees right
emeet-pixy tilt rel-5    # Relative: tilt 5 degrees down
emeet-pixy zoom rel+5    # Relative: zoom in 5
```

### Audio

| Command                 | Description              |
| ----------------------- | ------------------------ |
| `emeet-pixy audio`      | Cycle to next audio mode |
| `emeet-pixy audio nc`   | Noise cancellation       |
| `emeet-pixy audio live` | Live (raw)               |
| `emeet-pixy audio org`  | Original                 |

### Gesture Control

| Command                     | Description             |
| --------------------------- | ----------------------- |
| `emeet-pixy gesture-on`     | Enable gesture control  |
| `emeet-pixy gesture-off`    | Disable gesture control |
| `emeet-pixy toggle-gesture` | Toggle gesture control  |

### Auto Mode

| Command                  | Description                                            |
| ------------------------ | ------------------------------------------------------ |
| `emeet-pixy auto`        | Show current auto mode                                 |
| `emeet-pixy auto <mode>` | Set auto mode (off, full, tracking-only, privacy-only) |
| `emeet-pixy auto-on`     | Enable full auto mode                                  |
| `emeet-pixy auto-off`    | Disable auto mode                                      |
| `emeet-pixy toggle-auto` | Toggle auto mode                                       |

### Presets

| Command                           | Description                         |
| --------------------------------- | ----------------------------------- |
| `emeet-pixy preset save <name>`   | Save current PTZ position as preset |
| `emeet-pixy preset load <name>`   | Recall a saved preset               |
| `emeet-pixy preset delete <name>` | Delete a preset                     |
| `emeet-pixy preset list`          | List all presets                    |

### Status and Diagnostics

| Command              | Description                                              |
| -------------------- | -------------------------------------------------------- |
| `emeet-pixy status`  | Full status (camera, audio, gesture, PTZ, in-call, auto) |
| `emeet-pixy sync`    | Sync daemon state from camera hardware                   |
| `emeet-pixy probe`   | Re-detect device (video + hidraw)                        |
| `emeet-pixy device`  | Show current video and hidraw device paths               |
| `emeet-pixy waybar`  | Output Waybar JSON                                       |
| `emeet-pixy version` | Show version                                             |

## Socket Protocol

Commands are sent as newline-delimited strings over the Unix socket. The daemon responds with a status string or `error: <message>` on failure.

## Error Handling

All commands return either a success message or an error string prefixed with `error: `. The `emeet-pixy` CLI prints these directly to stdout/stderr.
